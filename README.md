# Reclamá Bien (by LCA ITECH)

Sitio estático: `index.html`, `styles.css`, `app.js` y `assets/`. Sin backend, sin frameworks, sin trackers.
Funciona abriendo `index.html` o publicado en GitHub Pages (por ejemplo en `lcaitech.com/reclamos`).

- Todo el armado del reclamo corre en el navegador. No se envía ni se guarda ningún dato.
- Plantillas, rubros y links oficiales están en `app.js` (objetos `RUBROS`, `L`, `SRC`).
- Links oficiales verificados en noviembre de 2026. COPREC fue disuelto (Decreto 55/2025); ENRE y ENARGAS pasaron al ENReGE.
- `?static` en la URL desactiva la animación del hero (útil para capturas).
